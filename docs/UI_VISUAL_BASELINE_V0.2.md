# BatchRenamer UI Visual Baseline V0.2

## 定位

视觉语言冻结为 **Desktop SaaS / Modern Productivity Tool**，而不是传统 Win32 工具，也不是网页 Dashboard 的机械移植。

## 视觉原则

- 浅色极简：白色 Surface + #F5F7FA 左右浅灰应用背景。
- 主强调色：清晰的中性蓝，用于主 CTA、当前导航、焦点状态。
- 圆角：输入与按钮约 8px；大 Card 约 12px。
- 边界：细浅灰边框优先，阴影非常克制或不使用。
- 信息密度：适中偏紧凑；面向高频桌面生产力使用。
- 主体：文件数据表格永远是最大视觉区域。
- 新名称 > 原名称 > 来源路径：建立明确的信息层级。
- 状态色只用于小面积 badge，不铺大面积彩色背景。

## 布局

```text
TitleBar
┌──64px Nav──┬──────────────────────────────────────────────┐
│ 重命名      │ 页面标题 / 简述                  添加文件 CTA │
│ 历史        ├──────────────────────────┬───────────────────┤
│             │ 搜索/筛选/排序            │ 重命名规则        │
│ 设置        │ 文件 DataGrid             │ 单一连续规则面板   │
│             │                           │                   │
└─────────────┴──────────────────────────┴───────────────────┘
              状态 / Preview latency              执行重命名
```

## 不采用

- Mica / Acrylic 作为主视觉；
- 大面积半透明；
- 霓虹、发光、赛博朋克；
- 厚重阴影；
- 强渐变；
- SaaS 网站常见的大量无意义 KPI 卡片；
- 为了“像后台”强行分页。大量本地文件继续使用虚拟化滚动。

## V0.2 与 V0.1 的差异

- 顶部传统 Toolbar 改为真正的 Page Header + CTA。
- 加入 64px 窄侧栏，但只保留真实产品需要的少量入口。
- 右侧由多张 Inspector Card 改成一张连续“重命名规则”面板。
- 搜索、问题筛选、排序集中在 DataGrid 顶部。
- 主 CTA 固定蓝色，建立明确视觉层级。
- 去掉 Mica 主视觉依赖。
