# BatchRenamer UI Visual Baseline V0.3

## 定位

Modern light Desktop SaaS / productivity tool，而不是网页后台皮肤，也不是传统 Windows 属性工具。

## 冻结视觉语义

- 主背景：浅灰；Surface：白；
- 主强调：克制蓝；
- 圆角：8–12 px；
- 阴影：不作为主要层级手段，优先浅边框；
- 高信息密度但保持明确对齐；
- 禁止玻璃拟态、霓虹、厚重阴影、夸张渐变；
- 主表格始终是工作区核心。

## V0.3 新增

- 规则栏使用软 Section，不堆重卡片；
- 控件 Accent 强制与产品蓝一致；
- ScrollBar 平时极弱，交互时增强；
- Excluded / Unchanged / Ready / Error 必须视觉可区分；
- ScrollBar 可用性优先于数学比例精确，Thumb 有最小可抓取尺寸。
