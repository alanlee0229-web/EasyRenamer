# BatchRenamer V0.45 — Windows 简化验收

本轮只验收信息架构与搜索栏，不重复执行整套 Validation 测试。

## A. 搜索栏

1. 启动程序。
2. 确认搜索框不再占满 62 px 工具栏高度，应为紧凑输入框。
3. 点击输入，检查光标与 Placeholder 基线。
4. 输入部分文件名，确认过滤仍正常。

通过条件：视觉紧凑、上下居中、输入和过滤无回归。

## B. 设置入口

1. 点击左下角齿轮。
2. 应出现居中的“设置与高级”窗口层。
3. 点击“常规设置”和“高级规则”切换。
4. 点击 × 关闭。
5. 再打开后按 Esc 关闭。
6. 再打开，点击卡片外侧遮罩关闭。

通过条件：三个关闭方式都可靠；设置层不影响底层主界面。

## C. 高级规则

1. 主界面把“原名称”设置为保留模式。
2. 齿轮 → 高级规则。
3. 勾选“启用高级规则”。
4. 查找 `IMG_`，替换为 `Photo_`。
5. 返回主界面观察预览。
6. 再进入高级规则，把大小写切换到任一非“保持不变”模式。
7. 关闭“启用高级规则”。

通过条件：
- 开启时高级规则参与预览；
- 关闭后高级效果立即停止；
- 再次开启时此前参数仍然存在。

## D. 主工作区减负

确认右侧主规则区只保留：

- 基础命名；
- 连续编号；
- 一条低权重“高级规则已收纳到设置”的提示。

不应再常驻显示查找替换和大小写卡片。

## E. 性能回归

按 `Ctrl + Shift + T` 加载 20,000 项。

通过条件：
- 列表仍可正常滚动；
- Preview latency 与 V0.4R 系列保持同一数量级；
- 打开 / 关闭设置不造成持续 CPU 占用。
