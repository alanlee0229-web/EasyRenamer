# BatchRenamer V0.46 Windows 简化验收

这一轮不需要重新跑完整 Validation 套件，重点检查信息架构和焦点行为。

## A. 设置与可选功能

1. 启动程序。
2. 右侧默认只应看到“基础命名”和“连续编号”。
3. 点击左下角齿轮。
4. 设置窗口中应只看到“可选功能”，包含：
   - 查找替换；
   - 大小写转换。
5. 设置窗口里不应出现查找框、替换框或大小写下拉框。
6. 勾选“查找替换”，关闭设置。
7. 右侧主规则栏应新增“查找替换”卡片。
8. 再进入设置取消勾选，主规则栏中的该卡片应完全消失。
9. 对“大小写转换”重复相同步骤。

## B. 功能停止 / 参数保留

1. 启用“大小写转换”。
2. 主面板把大小写改为“全部大写”。
3. 确认预览变为大写。
4. 设置中关闭“大小写转换”。
5. 右侧大小写卡片应消失，预览恢复为不执行大小写转换的结果。
6. 再次启用，卡片重新出现，并仍记得此前“全部大写”的选择。

## C. 搜索框焦点

1. 点击搜索框，确认 Caret 正常闪烁。
2. 点击文件表格任意行：Caret 应停止闪烁。
3. 再点击搜索框，然后点击右侧规则卡片空白处：Caret 应停止闪烁。
4. 再点击搜索框，然后点击“排序”按钮：Caret 应停止闪烁，同时排序按钮仍正常响应。
5. 按 `Ctrl+F`：搜索框应获得焦点。
6. 按 `Esc`：搜索框应退出输入状态。
7. 搜索框有文字时点击别处：文字保留，但 Caret 不再闪烁。

## D. 主界面清洁度

确认主界面不再出现：

- “高级规则已收纳到设置”；
- “打开设置”；
- “拖动行即可改变编号顺序”；
- “已接入真实只读校验”；
- “安全预览模式 · 当前不会写入磁盘”；
- 每一行重复的绿色“将改名”标签；
- 尚未实现的历史导航按钮。

错误、警告、“未参与”和“无变化”等有意义状态仍应正常显示。

## E. 快速性能回归（可选）

按 `Ctrl+Shift+T` 加载 20,000 项，确认滚动和预览没有明显退化即可。
