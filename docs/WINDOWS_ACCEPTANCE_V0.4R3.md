# BatchRenamer V0.4R3 — Windows 简化验收

本轮只验证 UI 分层和下拉框视觉/交互，不重复 V0.4R 的完整 Validation 测试。

## 1. 基础界面

启动程序后：

- 右侧默认只看到“基础命名”“连续编号”“高级规则”；
- “查找替换”“大小写转换”不应常驻占用空间；
- 原名称、编号位置等下拉框应是白色/浅色风格，不再是突兀的原生灰块。

## 2. 下拉框可靠性

分别点击：

1. 原名称；
2. 连续编号 → 位置；
3. 打开高级规则 → 大小写转换。

三者都应能正常展开、鼠标选择、键盘上下选择和关闭，不应再次出现无法展开的问题。

## 3. 高级规则

点击“高级规则”：

- 查找替换与大小写转换出现；
- 再点击一次应收起。

随后验证隐藏规则不会偷偷生效：

1. 打开高级规则；
2. 把大小写设为“全部大写”；
3. 确认左侧新名称变成大写；
4. 收起/关闭高级规则；
5. 左侧应立即恢复为“不应用大小写转换”的结果。

重新打开高级规则后，原先选择的“全部大写”可以仍保留，并重新生效。

## 4. 视觉检查

重点看三个下拉框：

- 正常状态：白色或极浅背景 + 浅灰边框；
- Hover：边框轻微增强；
- Focus：蓝色强调；
- 与周围 TextBox 的高度、文字基线和视觉重量协调。

若上述四项通过，本轮即可认为通过。
