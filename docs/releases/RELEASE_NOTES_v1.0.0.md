# easy重命名 / BatchRenamer v1.0.0

## Highlights

- Modern Windows batch renaming UI
- Live Preview and Validation
- Natural Sort and manual ordering
- Prefix, suffix, and sequence rules
- Optional Find & Replace and Case Conversion
- Safe two-phase rename transactions
- Undo
- Crash and startup recovery
- Portable single-file Windows app

## Safety

- No overwrite
- No silent skip
- No automatic suffix conflict resolution
- Durable journal
- Recovery fails closed
- Qualified with 20,000 real-file transaction and undo operations

## Platform

Windows x64. The app is self-contained and does not require a separate .NET installation.

## Integrity

Verify the download with `SHA256SUMS.txt`.
